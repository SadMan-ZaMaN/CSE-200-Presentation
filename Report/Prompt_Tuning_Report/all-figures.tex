%  per page, into all-figures.pdf. main.tex includes those pages, so the
%  report itself compiles quickly (Overleaf's free plan has a short
%  compile time limit, and TikZ/pgfplots drawings are slow to typeset).
%
%  You only need to recompile this file after changing a drawing in
%  figures.tex. On Overleaf: Menu -> Main document -> all-figures.tex,
%  recompile, download the PDF, upload it as all-figures.pdf, and switch
%  Main document back to main.tex.
%
%  The font setup matches main.tex so the figures look identical.
%  Keep the page order below in sync with the list in main.tex.
% =====================================================================
